💡 Need a quick memory refresher?
  • Categorical Nominal: Labels or names with no order (e.g., eye color).
  • Categorical Ordinal: Categories with a natural order (e.g., shirt sizes: S, M, L).
  • Numerical Discrete: Whole numbers that you count (e.g., number of pets).
  • Numerical Continuous: Measurements that can take any value or decimal (e.g., height, weight).
